# KEYFALL — 악기 리듬게임

피아노 · 베이스 · 일렉기타 · 드럼 4가지 악기로 치는 웹 리듬게임. 빌드 과정 없는 순수 HTML/JS.

접속하면 악기 탭(피아노 / 베이스 / 일렉기타 / 드럼) → 곡 선택 → 난이도(이지·노말·하드) → 시작. 세부 설정은 ⚙ 설정 안에 있습니다.

## 실행

Chrome 또는 Edge에서 실행 (Web MIDI 지원 브라우저).

```bash
npx serve .          # 또는: python -m http.server 8000
```

`http://localhost:...` 접속 → MIDI 권한 허용. (`index.html` 더블클릭도 대부분 동작하지만 로컬 서버를 권장)

## 악기

- **베이스 (4레인)** / **일렉기타 (5레인)**: 음높이 흐름을 따라 레인이 정해지고, 친 노트가 실제 악기 소리로 납니다. 키보드 베이스 `D F J K`, 기타 `D F Space J K`
- **일렉기타 전용곡**: 산왕의 궁전에서(점점 빨라지는 록 편곡), 로망스(아르페지오)

## 피아노 보기

- **7키**: 도·레·미·파·솔·라·시 7개 레인. 옥타브 무관, 검은건반은 아래 흰건반 레인으로 처리. 키보드 `S D F Space J K L`
- **피아노**: 88건반(A0–C8) 전체 화면. 정확한 음높이 필요. 키보드 흰건반 `1~0 q~m`(C2–C7), 검은건반 `Shift`+키, 양 끝 확장 건반(점 표시)은 `Ctrl`/`Alt`+키

- **드럼**: 크래시·하이햇·스네어·킥·하이탐·로우탐·라이드 7레인. 전자드럼(MIDI 10번 채널) 그대로 연결, 피아노 건반은 도~시가 각 레인, 키보드 `S D F Space J K L`

## 난이도

- **이지**: 오른손 멜로디(화음은 맨 위 음), 빠른 음 생략 / 드럼은 킥·스네어·크래시
- **노말**: 오른손 (화음은 맨 위 음) / 드럼은 + 하이햇 8분·탐·라이드
- **하드**: 양손 모든 음 / 드럼 전부
- 생략된 음은 자동 반주로 들려서 음악은 그대로 유지

## 모바일

휴대폰에서는 자동으로 가로 화면(전체 화면 + 방향 고정, 안 되는 기기는 화면 회전)으로 바뀌고 터치로 연주합니다. 피아노 모드는 곡 음역만 표시해서 건반을 누르기 쉽게 합니다.

## 플레이 방식

- **일반**: 곡이 계속 진행, 놓친 노트는 MISS
- **연습 (기다리기)**: 노트를 칠 때까지 곡과 반주가 멈춤

## 기능

- 판정 COOL ±45ms / GOOD ±90ms / BAD ±150ms, 콤보·점수·HP·랭크, FAST/SLOW 표시
- 롱노트 (0.8초 이상 음은 누르고 있기)
- 반투명 스크롤 악보 (큰보표, 투명도 조절), 건반 위 오로라 조명 효과
- 반주 악기: 피아노·스트링·베이스·드럼 등 (내장곡에 기본 포함)
- `.mid` 파일 불러오기 → 파트(트랙·채널)별로 연주 / 반주 / 끔 선택, GM 악기에 맞는 음색으로 재생
- 연습용 재생 속도(50~100%), 판정 오프셋, 오토 플레이

## 곡 추가하기

`songs/` 폴더에 `.mid` 파일을 넣고 `songs/songs.json`에 항목을 추가합니다 (`title`, `artist`, `file`, `drumStyle`, `credit`, 템포 표시가 없는 파일은 `tempoScale`). 저작권이 끝났거나 공개 라이선스인 곡만 올리세요.

## 구조

| 파일 | 역할 |
|---|---|
| `js/midi-file.js` | SMF 파서 (템포 맵, 트랙·채널별 파트 분리) |
| `js/songs.js` | 내장곡 + 간단한 음표 표기법 (`C4/1`, `C4+E4/2`, `R/.5`) |
| `js/audio.js` | Web Audio 신스 (피아노·스트링·베이스 등 + 드럼 키트) |
| `js/score.js` | 스크롤 악보 렌더링 |
| `js/input.js` | Web MIDI + 키보드 입력 |
| `js/game.js` | 판정·노트 처리·캔버스 렌더링 |
| `js/main.js` | 메뉴·설정·화면 전환 |
